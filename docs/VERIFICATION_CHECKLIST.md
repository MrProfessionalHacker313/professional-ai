## TROUBLESHOOTING

### Not Indexed After 1 Week
- Check robots.txt for accidental blocking
- Resubmit sitemap in Search Console
- Request indexing via URL Inspection tool
- Ensure no `noindex` tags on pages

### Low CTR (< 1%)
- Rewrite meta titles and descriptions
- Add structured data for rich results
- Improve page load speed
- Test different ad headlines

### High Bounce Rate (> 70%)
- Improve page load speed
- Ensure mobile responsiveness
- Add clear CTAs above the fold
- Improve content quality and relevance

### Low Conversion Rate (< 2%)
- Simplify sign-up flow
- Add more social proof
- Offer free trial without credit card
- Improve page copy and CTAs
